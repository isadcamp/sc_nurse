# Sprint 11 — การยกเครื่อง UI/UX, Design System และแม่แบบใบจัดเวรทางการ (UI/UX Revamp, Design System & Official Hospital Templates)

ที่มา: [plan.md](plan.md) ระยะ 11 | มาตรฐาน: [rule.md](rule.md)
ต้องการ: Sprint 9 และ Sprint 10

## เป้าหมาย

ยกเครื่องประสบการณ์การใช้งาน (UI/UX) และระบบแม่แบบ (Templates) ทั้งหมดของระบบจัดตารางเวรพยาบาลให้มีความทันสมัย สวยงาม สะอาดตา (Clean Medical SaaS Theme) ลดขั้นตอนการทำงานที่ซ้ำซ้อน จัดการเวรได้รวดเร็วแบบคลิกเดียวเปลี่ยน (Fast Interaction) พร้อมแถบสรุปกำลังคนและตัวช่วยตรวจความถูกต้องในตารางแบบ Real-time และระบบแม่แบบสำหรับพิมพ์ใบตารางเวรทางการขนาด A4 แนวนอนตามมาตรฐานโรงพยาบาล

## สิ่งที่ส่งมอบ

### 1. ระบบธีมและภาษาการออกแบบใหม่ (Clean Medical Design System)

- **โทนสีหลัก (Color Tokens)**:
  - พื้นหลังหลัก: สีขาวสะอาดตา และเทาอ่อน `Slate-50` / `Gray-50`
  - สีอัตลักษณ์หลัก: สีฟ้าครามการแพทย์และสีเขียวหัวเป็ด `Teal-600` / `Indigo-600`
  - เส้นขอบและเงามน: `border-slate-200`, `rounded-xl`, `shadow-sm`
- **ระบบรหัสสีของกะเวร (Shift Badge Tokens)**:
  - 🌅 **เวรเช้า (ช / M)**: สีเหลืองอำพัน/ทอง (`bg-amber-100 text-amber-900 border-amber-300`)
  - 🌇 **เวรบ่าย (บ / E)**: สีส้มพีช (`bg-orange-100 text-orange-900 border-orange-300`)
  - 🌙 **เวรดึก (ด / N)**: สีกรมท่า/ม่วงคราม (`bg-indigo-100 text-indigo-900 border-indigo-300`)
  - ⚡ **เวรควบ (ชบ, ดบ)**: สีฟ้าเทอร์ควอยซ์ (`bg-teal-100 text-teal-900 border-teal-300`)
  - 🟢 **วันหยุด (อ / X)**: สีเทาสว่าง (`bg-slate-100 text-slate-600 border-slate-200`)
  - 🔒 **วันลา (L)**: สีม่วงพาสเทล พร้อมไอคอนกุญแจล็อก (`bg-purple-100 text-purple-900 border-purple-300`)
  - 🚩 **วันหยุดนักขัตฤกษ์ (★)**: แถบสีชมพูแดงอ่อนบนหัวคอลัมน์ (`bg-rose-50 text-rose-700`)
- **ความสอดคล้องของหน้าต่าง (Modal Unification)**:
  - ปรับเปลี่ยนหน้าต่างทั้งหมด (วันลา, วันหยุด, จัดการเจ้าหน้าที่, จัดการวอร์ด, นโยบาย) ให้เป็นธีมสว่างคลีน (Light Theme) เข้าชุดกับหน้าจอหลัก 100%

1. **Top Navigation Bar**:
   - โลโก้และชื่อระบบ `NurseFlow`
   - ตัวเลือกหน่วยงาน (Ward Selector)
   - ตัวเลือกเดือน/ปี พ.ศ. และ ค.ศ.
   - ป้ายสถานะตารางเวร (Status Badge: Draft, Review, Approved, Published)
   - โปรไฟล์ผู้ใช้งาน และปุ่มสลับบทบาท (Role Switcher)
2. **Left Action Rail (แผงเครื่องมือซ้ายมือ)**:
   - ปุ่มหลัก: `✨ จัดเวรอัตโนมัติ (AI Solver)`
   - เครื่องมือ: **Shift Brush Palette (แปรงแต้มเวร)** เลือกกะแล้วคลิกลงตารางต่อเนื่อง
   - เมนูตั้งค่าและจัดการ: เจ้าหน้าที่ (Staff), วันลา (Leave), วันหยุด (Holidays), นโยบาย (Policy) พร้อม Badge ตัวเลขแจ้งเตือนงานค้าง
3. **Center Main Matrix Grid (พื้นที่ตารางเวรกลางจอ)**:
   - ตารางเวร 31 วันเต็มจอ ตรึงหัวตารางด้านบนและคอลัมน์ชื่อด้านซ้าย (Sticky Header & Left Col)
   - คอลัมน์ขวาสุด: สรุปเวร ช/บ/ด/อ/L และชั่วโมงรวมรายคน
   - แถวล่างสุด: สรุปยอดกำลังคน เช้า/บ่าย/ดึก รายวันแบบ Real-time
4. **Right Insights Panel (แผงข้อมูลและตัวตรวจกฎขวามือ)**:
   - รายละเอียดความปลอดภัยของกำลังคน (Staffing Coverage)
   - รายการข้อผิดพลาดและกฎที่ละเมิด (Violations Guard) แสดงจุดที่ต้องแก้ไขทันที
   - ปุ่มดำเนินการ Workflow (ส่งตรวจ / อนุมัติ / ประกาศใช้งาน)

### 3. การโต้ตอบและการแก้ไขเวรความเร็วสูง (Fast Interaction & Editing)

- **Quick Floating Dropdown Menu**: คลิกที่ช่องเวรแล้วแสดงเมนูลอยขนาดกะทัดรัดให้เลือกเปลี่ยนเวรได้ในคลิกเดียว ไม่ต้องเปิด Dialog บังหน้าจอ
- **Shift Brush Mode (โหมดแปรงแต้มกะ)**:
  - คลิกเลือกกะจากแผงซ้าย (เช่น กะ `ช`)
  - นำเมาส์ไปคลิกแต้มช่องพยาบาลในตารางได้ต่อเนื่องอย่างรวดเร็ว
- **แป้นพิมพ์ลัด (Keyboard Shortcuts)**:
  - รองรับการกดปุ่มบนคีย์บอร์ดเพื่อเปลี่ยนเวร: `C` (เช้า), `B` (บ่าย), `D` (ดึก), `O` (Off), `L` (Leave), `Del` (ล้างค่า)

---

### 4. แถบสรุปกำลังคนและตัวตรวจกฎสดในตาราง (In-Grid Live Stats)

- **Daily Coverage Summary Row (ใต้ตารางทุกวัน)**:
  - แสดงจำนวนเวรเช้า (M), บ่าย (E), ดึก (N) ของแต่ละวัน
  - ไฮไลต์ **สีแดง ⚠️** ทันทีหากกำลังคนต่ำกว่าเกณฑ์ขั้นต่ำของวอร์ด
  - ไฮไลต์ **สีเขียว ✅** เมื่อกำลังคนครบถ้วนตามเกณฑ์
- **Nurse Summary Column (ขวาสุดของแต่ละคน)**:
  - สรุปยอดรวม: จำนวนเวรเช้า, บ่าย, ดึก, วันหยุด (Off), วันลา (Leave)
  - สรุปชั่วโมงทำงานรวมทั้งเดือน พร้อมเทียบกับชั่วโมงเป้าหมาย (Variance)

---

### 5. แม่แบบการพิมพ์ใบตารางเวรทางการขนาด A4 (Official A4 Print Template)

- **Print View Mode & CSS Print Stylesheet**:
  - ออกแบบสำหรับกระดาษ **A4 แนวนอน (Landscape)** พอดีหน้า 100% ไม่ล้น ไม่ตกขอบ
  - ฟอนต์และเส้นตารางคมชัด ปรับโทนสีให้ประหยัดหมึกพิมพ์
  - หัวเอกสารทางการของโรงพยาบาลและหอผู้ป่วย
  - ช่องลงนามอนุมัติท้ายเอกสาร:
    - ช่องลงนาม: **หัวหน้าหอผู้ป่วย** (ผู้จัดทำ/เสนอ)
    - ช่องลงนาม: **หัวหน้าฝ่ายการพยาบาล / ผู้อำนวยการ** (ผู้อนุมัติ)

## การทดสอบและการตรวจรับ (Verification & Acceptance Criteria)

1. **Visual Consistency**: หน้าจอหลักและ Modals ทุกตัวใช้ Light Medical Theme เดียวกันทั้งหมด ไร้รอยต่อ
2. **Speed & Usability**: สามารถคลิกเปลี่ยนเวรหรือใช้แปรงแต้มเวรได้อย่างรวดเร็วโดยไม่ต้องเปิด Modal Popup
3. **Live Stats Accuracy**: แถวสรุปกำลังคนใต้ตารางและคอลัมน์ขวามือคำนวณสดถูกต้องทันทีที่มีการแก้เวร
4. **Print Accuracy**: กดพิมพ์ตารางเวรแล้วจัดหน้าลงกระดาษ A4 แนวนอนได้พอดี พร้อมหัวเอกสารและช่องลงนามครบถ้วน
5. **Responsiveness & Cross-browser**: รองรับการใช้งานบนหน้าจอมาตรฐาน (Desktop 1366x768 ขึ้นไป, Full HD, และ Tablet)

## Definition of Done

- [x] แปลงธีมและดีไซน์ทั้งหมดเป็น Clean Medical SaaS Theme (White / Slate / Teal)
- [x] ปรับโครงสร้างหน้าจอหลักเป็น 3 ส่วน (Topbar, Left Action Rail, Center Matrix Grid, Right Insights)
- [x] พัฒนาระบบ Quick Shift Dropdown และ Shift Brush Palette สำหรับแต้มเวรความเร็วสูง
- [x] พัฒนาแถวสรุปยอดกำลังคนใต้ตาราง (Live Coverage) พร้อมไฮไลต์สีแดงเตือนเมื่อคนไม่พอ
- [x] พัฒนาคอลัมน์สรุปยอดเวรและชั่วโมงรวมรายบุคคลด้านขวาสุดของตาราง
- [x] ปรับปรุง Modals ทั้งหมด (Holiday, Leave, Staff, Ward, Policy) ให้เป็นธีมสว่างคลีนเข้าชุดกัน
- [x] พัฒนาหน้า Print Template A4 แนวนอน พร้อมช่องลงนามทางการ
- [x] ทดสอบ Build ผ่าน 100% ไร้ข้อผิดพลาด
