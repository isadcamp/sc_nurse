## เป้าหมาย

สร้างระบบตั้งค่านโยบายที่ปรับได้โดยไม่แก้โค้ด, ปฏิทินวันหยุด, อัตรากำลัง, เป้าหมายรายคน และ workflow คำขอ/อนุมัติวันลา

## สิ่งที่ส่งมอบ

### 1. ปฏิทินวันหยุด (Holiday Calendar)

- เก็บวันหยุดตามวันที่จริง (ไม่สมมติว่าตรงวันเดิมทุกปี)
- คัดลอกไปปีถัดไปเป็นร่างให้ตรวจและยืนยันได้
- Mini Calendar แสดงวันธรรมดา / เสาร์อาทิตย์ / วันหยุดพิเศษ

### 2. ระบบตั้งค่า AUTO (Scheduling Policy)

#### ขอบเขตและสิทธิ์

- **ผู้ดูแลนโยบาย (Admin)** → กำหนดกรอบกลาง, ข้อบังคับ, สิทธิ์ที่แต่ละหน่วยปรับได้
- **หัวหน้าหน่วย** → สร้างชุดตั้งค่าจากกรอบกลาง + เป้าหมายรายเดือน + ข้อจำกัดรายบุคคล
- ค่าระดับหน่วย/รายคนห้ามผ่อนปรนข้อบังคับกลาง:
  - เพดาน → ใช้ค่าที่เข้มกว่า
  - ขั้นต่ำ → ใช้ค่าที่สูงกว่า
  - ชนิดเวร → ต้องได้รับอนุญาตครบทุกระดับ

#### กลุ่มข้อมูลบนหน้าตั้งค่า

| กลุ่ม | ค่าที่กำหนดได้ | วิธีใช้ |
|---|---|---|
| แบบเวร | เปิด/ปิดเวร, ช่วงเวลา, ผู้ที่ขึ้นเวรควบได้ | ใช้แบบเวรที่มีเวอร์ชัน ตรวจเวลาจริงทุกช่วง |
| อัตรากำลัง | ขั้นต่ำรายช่วงเวลา, RN/PN, หัวหน้า, ทักษะ, แม่แบบวันธรรมดา/วันหยุด, ข้อกำหนดเฉพาะวัน | ข้อบังคับ + โควตาตามชื่อเวรเป็นเป้าหมายเสริม |
| ชั่วโมงงาน | เพดานต่อเดือน, ย้อนหลัง 7 วัน, ช่วงเลื่อน 24 ชม., ชั่วโมงต่อเนื่องสูงสุด | ตรวจภาระงานรวมและรอยต่อเดือน |
| เวลาพัก | พักขั้นต่ำระหว่างช่วงงาน, พักหลังชุดเวรยาว/กลางคืน | ตรวจจากเวลาเริ่ม/สิ้นสุดจริง |
| วันต่อเนื่อง | วันทำงานติดกันสูงสุด, เวรกลางคืนติดกันสูงสุด | ใช้ประวัติก่อนเริ่มเดือนร่วมด้วย |
| เวรควบ | สิทธิ์รายคน, เพดานรายเดือน, เอกสารนโยบาย | ไม่ข้ามกฎชั่วโมงและการพัก |
| OFF และลา | OFF ขั้นต่ำ/เป้าหมายรายคน, ชั่วโมงเป้าหมายหลังปรับลา | รุ่นแรกหัวหน้าระบุเป้าหมาย |
| บุคลากร | เวรที่ขึ้นได้, ข้อจำกัดรายคน, พี่เลี้ยง, ช่วงอบรม/ภารกิจอื่น | แยกชั่วโมงงานจากเวลาที่พร้อมดูแลผู้ป่วย |
| ความเป็นธรรม | น้ำหนักชั่วโมง, ภาระกลางคืน, วันหยุด, ความต้องการรายคน | soft constraints แสดงคะแนนแยก |
| การคำนวณ | เวลาสูงสุด, seed, ขอบเขตจัดใหม่ | จำกัดค่าสูงสุดฝั่ง server |

#### ข้อกำหนดของแต่ละ field

- ชนิดข้อมูล, หน่วย, ช่วงค่าที่รองรับ, คำอธิบาย, ตัวอย่าง, required/optional
- ห้ามใช้ JSON/ข้อความอิสระเป็นหน้าตั้งค่าหลัก
- ห้ามประมวลผลข้อความผู้ใช้เป็นโค้ด/สูตรที่รันได้

#### ค่าบังคับ vs ค่าแนะนำ

- กฎแต่ละข้อมีรหัสคงที่ ระบุ hard/soft และพารามิเตอร์ที่รองรับ
- **ข้อบังคับที่ห้ามลดเป็น soft**: ไม่ซ้อนเวลา, ไม่ทับลาอนุมัติ, สิทธิ์บุคลากร, รักษาเวรล็อก
- **ค่าแนะนำ**: พัก 8h, ดึกสูงสุด 2 คืน → ต้องยืนยันก่อนใช้จริง
- ค่าที่ไม่ทราบ ≠ ศูนย์หรือไม่จำกัด
- เวร 16h ต้องมีนโยบายยืนยัน + เพดานชั่วโมง + สิทธิ์รายคน ก่อน AUTO ใช้

#### สถานะและเวอร์ชัน

1. `draft` — สร้างจากแม่แบบ/คัดลอก, แสดงค่าที่ขาด
2. `validate` — ตรวจรูปแบบ, ขอบเขตสิทธิ์, ความขัดแย้ง
3. จำลองกับข้อมูลเดือนเป้าหมาย (ไม่แก้ตารางจริง)
4. `confirmed` — ผู้มีสิทธิ์ยืนยัน + ช่วงวันที่ใช้ได้
5. แก้ชุดที่ยืนยันแล้ว → สร้างเวอร์ชันร่างใหม่ ห้ามแก้ย้อนหลัง

### 3. อัตรากำลังตามช่วงเวลา (Staffing Requirements)

- แม่แบบแยก: วันธรรมดา / เสาร์อาทิตย์ / วันหยุดพิเศษ
- ลำดับ: **ค่าเฉพาะวัน → วันหยุดพิเศษ → เสาร์อาทิตย์ → วันธรรมดา**
- กำหนดขั้นต่ำตามช่วง: 00–08, 08–16, 16–20, 20–24
- แต่ละช่วง: จำนวน RN/PN, หัวหน้า, ทักษะที่จำเป็น
- นับบุคลากรจริงในแต่ละช่วงโดยไม่ซ้ำคน

### 4. เป้าหมายรายบุคคล/รายเดือน (Monthly Targets)

- ชั่วโมงเป้าหมาย/สูงสุดต่อเดือน
- OFF ขั้นต่ำ/เป้าหมาย
- ชั่วโมงเป้าหมายหลังหักลา (หัวหน้าระบุและยืนยัน)
- ความต้องการพิเศษ:
  - ขอ ช ทุกวันจันทร์
  - ขอ OFF วันเสาร์
  - ไม่ต้องการดึกติดกัน
  - ขอ/หลีกเลี่ยงเวรในวันที่ระบุ
- ช่องหมายเหตุ (ยังไม่เป็นกฎบังคับจนหัวหน้ายืนยัน)

### 5. ระบบคำขอและอนุมัติวันลา (Leave Management)

- เจ้าหน้าที่ส่งคำขอ → หัวหน้าอนุมัติ/ปฏิเสธ พร้อมเหตุผลและประวัติ
- คำขอ **รออนุมัติ** = ความต้องการ (soft)
- คำขอ **อนุมัติแล้ว** = ข้อบังคับ (hard)
- วันลา ≠ OFF; ช่องว่างที่ยังไม่จัด ≠ OFF
- อนุมัติหลังมีตารางแล้ว → แจ้งรายการที่ได้รับผลกระทบ + ตรวจตารางใหม่
- ชั่วโมงทำงานจริงไม่รวมวันลา
- ลาเต็มวันในรุ่นแรก

### 8. Frontend

- หน้าปฏิทินวันหยุด (Mini Calendar)
- หน้าตั้งค่า AUTO แบ่งกลุ่ม (10 กลุ่ม)
- หน้าสรุปค่าที่มีผลจริงพร้อมแหล่งที่มา
- หน้าเปรียบเทียบเวอร์ชัน
- หน้าอัตรากำลัง (แม่แบบ + เฉพาะวัน)
- หน้าเป้าหมายรายบุคคล
- หน้าคำขอลา + การอนุมัติ
- แสดง loading, empty, success, partial, failure states

## การทดสอบ

- Policy version lifecycle: draft → validate → confirm → new version
- ค่าระดับหน่วยผ่อนกฎกลางไม่ได้
- ค่าที่ขาด/ผิดช่วงค่า → ปฏิเสธ
- Leave request workflow: pending → approved/rejected
- อนุมัติลาหลังมีตาราง → ตรวจผลกระทบ
- วันหยุดพิเศษทับเสาร์อาทิตย์
- อัตรากำลังลำดับ: เฉพาะวัน > วันหยุดพิเศษ > เสาร์อาทิตย์ > วันธรรมดา
- Integration tests ใช้ `nurse_test`
